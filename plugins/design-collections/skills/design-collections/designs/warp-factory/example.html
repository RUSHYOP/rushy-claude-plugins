0.8.2

20 Aug 2026 patch

Pane movement across tabs, and a fix for the detach race that could strand a session.

+pane move <id> --tab <id> --split right|down
+pane move --new-tab / --new-workspace
−pane join (superseded by pane move)
  • Moving the last pane out of a tab now closes the tab cleanly.
  • Detach no longer races the server on slow sockets.

Release policy

How are versions numbered?
Semver. Patch releases never contain breaking changes; minor releases may, and always ship a migration note in this changelog.
What counts as breaking?
Any change that requires editing your config, or that changes the meaning of an existing keybinding or CLI flag.
Where do I report a regression?
Open an issue with the output of herdr status and the release you upgraded from.

Every release is reproducible from the tag.

Build inputs are pinned and the checksum is published with the binary.
