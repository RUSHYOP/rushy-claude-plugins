# excalidraw-pages

One skill: **excalidraw-page** — generate self-contained HTML documents in a fixed
Excalidraw-style design system (paper + ink, hand-drawn Mermaid diagrams, sketch-border
cards, marker highlights, sticky section nav). The design never changes; the content does.

Origin: extracted from the CMD 2.0 rewrite-plan page (2026-07-29) so every future plan,
architecture doc, review, or proposal ships in the same visual language.

- `skills/excalidraw-page/SKILL.md` — usage rules and workflow
- `skills/excalidraw-page/assets/template.html` — the complete working template (open it in a browser as-is)
- `skills/excalidraw-page/references/components.md` — copy-paste markup catalog for every component
