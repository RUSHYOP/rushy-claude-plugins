1 Cards & Lists

Sketch cards carry the content. Alternate .sk / .sk.alt for varied hand-drawn borders; pick data-a accents by meaning (green = good/in-scope, red = risk/out, blue = neutral/design, orange = new, violet = agentic).

A green card
  • Lead bold — then the detail sentence, with tags where ownership matters 🤖 sonnet
  • Second point with inline code where precision helps.
  • Third point — keep 3–6 items per card.
A red card (alt border)
  • Risks, out-of-scope items, and counter-arguments live on red.
  • Mixing one .sk and one .sk.alt per row keeps the sketch feel organic.
Callout. One key insight per section can be promoted into a callout — accent border matches the point's mood (blue/green/orange/red).
